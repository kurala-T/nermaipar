NermaiPar

An omnipresent circuit breaker for digital misinformation

VerseHack 2026  |  Round 2 prototype documentation
Team Nermai TOPpers  |  12 November 2026

1. Project overview

NermaiPar helps a person pause a suspicious forward before they share it. It reads the message, says whether the claim is true, false, misleading, or unverified, names the trick, and offers a short reply that can be sent back without starting a fight.

The live checker is a Telegram bot. The website shows the full path a family would use: Detect, Explain, Respond, and Train. The website also walks through how the same check would look on WhatsApp and on a basic phone. Those two views are demonstrations. They are not connected to live WhatsApp or SMS networks.

2. Problem statement

Scary and urgent messages spread in family groups because they are easy to forward and hard to check in the moment. A health cure, a bank warning, or a half-true news story can move through dozens of chats before anyone opens a trusted source. People also avoid correcting an elder because the correction itself starts an argument.

The problem is not a lack of facts somewhere on the internet. The problem is the few seconds between receiving a forward and tapping the arrow. NermaiPar is built for that pause.

3. Proposed solution and objectives

  • Give a verdict in plain language: True, False, Misleading, or Unverified.
  • Answer a direct question, not only a pasted forward.
  • Fix obvious spelling so a messy message is still judged on its meaning.
  • Show the manipulation trick and a polite reply the user can paste back.
  • Keep the check where the message already is, starting with Telegram.
  • Teach the pattern on the website so the next forward is easier to spot.

4. How it works

1. The user sends a message to the Telegram bot, or pastes a sample on the website.

2. Greetings and messages about how to use the bot are answered as conversation. They are not stamped as hoaxes.

3. For a claim, the bot fixes a short list of common typos and searches current news headlines.

4. Those notes and the message go to Gemini, which returns a spoken answer, a verdict, the trick, and a paste-back line.

5. The bot first says it is checking, then replaces that line with the answer and adds an emoji reaction.

6. If the model returns nothing, a small saved list still blocks known health scams, fake bank links, and the claim that a currency note contains a tracking chip.

A weather question skips the hoax stamp and uses a live forecast instead.

5. Technologies and tools

  • Website: HTML, CSS, and JavaScript. No build step. It can be installed as a web app, and the shell works offline after the first load.
  • Bot: Python 3.11 on Telegram.
  • Verdicts: Gemini API. OpenRouter is wired as a fallback when a key is present.
  • Fresh context: a live news search is attached to each claim before the model answers. Weather uses the Open-Meteo forecast.
  • AI assistance was used while building the prototype. The team can explain each part of the check.

6. Key features

  • True, False, Misleading, and Unverified, each with a sentence a person can read aloud.
  • Spelling cleanup before the verdict, so typos do not hide the claim.
  • An emoji reaction on the user's message.
  • A reply written for a family chat, not for an argument.
  • Website flow: Detect, Explain, Respond, and a short training quiz.
  • Sample claims for a health scam, a bank-link scam, and a real space-agency launch.

7. What a judge can try

On Telegram, open the NermaiPar bot and send: "Did Nvidia get hacked this month?" The expected answer is True, with the October 2026 Brev cloud incident and no confirmed misuse. Then send a version that says the hack was today and that GPUs are exploding. The expected stamp is Misleading: the breach report is real, and the exploding-GPU part is not.

On the website, choose Health scam and press Analyze. Open Explain, then Respond, and copy the reply. The interface used for the demo is English.

8. Current limitations

  • A verdict can be wrong. The product tells people to confirm important claims with the original source.
  • News search can return a related headline that is not the same story. The model is told to ignore notes about a different story.
  • Gemini's built-in Google Search is over the free quota, so search uses a news feed instead.
  • WhatsApp and SMS in the website are simulated channels.
  • The bot has to be running for Telegram checks. It is not a 24-hour hosted service yet.
  • Do not send passwords, one-time codes, or card numbers. The bot is not a bank.

9. Future scope

  • Connect a real WhatsApp path so a forward never has to be copied into another app.
  • Put a source link on every verdict.
  • Cache the most common hoaxes for slow or offline connections.
  • Keep one public demo running through the judging window.
