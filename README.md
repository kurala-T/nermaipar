## What It Does
NermaiPar sits inside Telegram and Discord so you never have to leave your chat to check a suspicious forward:
- Gives one clear verdict: **True**, **False**, **Misleading**, or **Unverified**
- Fixes spelling mistakes in messy forwards automatically
- Explains the manipulation trick and writes a polite reply you can paste back to family elders
- Uses the Google Gemini API with live news headline search for the prototype, with a future roadmap to custom-train an open-source **Google Gemma** model
